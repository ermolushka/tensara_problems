
Multiply every element of a matrix by a scalar value:

$$
C[i][j] = A[i][j] \cdot s
$$

## Input:
- Matrix $A$ of size $M \times N$ stored in row-major order
- Scalar $s$ (float)

## Output:
- Matrix $C$ of size $M \times N$

## Test Case Sizes

- M=1024, N=1024
- M=2048, N=2048
- M=4096, N=4096
- M=8192, N=8192
